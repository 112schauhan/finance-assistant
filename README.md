# Finance Assistant

A personal document management system that automatically collects, organizes, and prepares financial documents for tax filing.

## Goals

- Automatic Gmail sync
- Invoice parsing
- OCR support
- AI metadata extraction
- Searchable documents
- One-click export for CA

## Tech Stack

### Frontend

- Next.js
- React
- Tailwind CSS
- TypeScript
- pnpm

### Backend

- FastAPI
- Python

### Database

- SQLite

### AI

- Ollama

### OCR

- OCRmyPDF
